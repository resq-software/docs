<Update label="July 2026" tags={["TypeScript", "Rust"]}>
  ## TypeScript — npm scope moved to `@resq-systems`

  The TypeScript packages moved from the `@resq-sw` scope to
  `@resq-systems` on 12 July 2026, restarting at `1.0.0`. **`@resq-sw` is not
  deprecated on npm, so installs still resolve — silently, to stale
  versions.** See the [TypeScript SDK](/sdks/typescript) page for migration
  steps.

  | Package | Version |
  |---------|---------|
  | `@resq-systems/http` | 2.0.1 |
  | `@resq-systems/analytics` | 2.0.1 |
  | `@resq-systems/dsa` | 2.1.0 |
  | `@resq-systems/security` | 1.0.5 |
  | `@resq-systems/ui` | 0.37.2 |
  | `@resq-systems/email-templates` | 0.6.2 |
  | `@resq-systems/constants` | 0.5.0 |
  | `@resq-systems/rate-limiting` | 0.4.2 |
  | `@resq-systems/decorators` | 0.4.0 |
  | `@resq-systems/helpers` | 0.4.0 |
  | `@resq-systems/logger` | 0.3.0 |
  | `@resq-systems/math` | 0.2.1 |
  | `@resq-systems/types` | 0.1.0 |

  `@resq-systems/math` and `@resq-systems/types` are new packages with no
  `@resq-sw` predecessor.

  Notable changes in this cycle:

  - `Result.all` is now generic (`Result<T, E>` rather than `any`) and
    short-circuits on the first error. The unused `control.ts` `Result` is
    deprecated.
  - `TokenBucketLimiter` and `LeakyBucketLimiter` use the
    `@resq-systems/dsa` queue for their FIFO waiter queues instead of
    hand-rolled array operations.
  - `getHashForObject` takes `unknown` rather than `any`.

<Update label="April 2026" tags={["Rust", "Python", ".NET", "TypeScript"]}>
  ## Rust — CLI tools renamed

  The seven CLI tools were renamed on 3 April 2026. The old crate names
  stopped at `0.1.9` and are no longer published; the new names continue the
  version series.

  | Was | Now |
  |-----|-----|
  | `resq-bin-explorer` | `resq-bin` |
  | `resq-cleanup` | `resq-clean` |
  | `resq-deploy-cli` | `resq-deploy` |
  | `resq-flamegraph` | `resq-flame` |
  | `resq-health-checker` | `resq-health` |
  | `resq-log-viewer` | `resq-logs` |
  | `resq-perf-monitor` | `resq-perf` |

  | Crate | Version |
  |-------|---------|
  | The seven tools above | 0.1.15 |
  | `resq-cli` | 0.2.6 |
  | `resq-tui` | 0.1.7 |
  | `resq-dsa` | 0.1.2 |
  | `resq-ai` | 0.1.0 (first release) |
