Border radius scale (px, email-safe). Mirrors the shipped `@resq-systems/ui`
`--radius-*` scale: `sm`→token (3px), `md`→control (4px), `lg`→panel (6px),
`xl` (panel + 4px = 10px). `full` is the pill radius (no UI counterpart).
