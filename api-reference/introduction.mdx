ResQ exposes two core APIs for disaster response coordination:

## Infrastructure API

Built with Rust/Axum. Handles persistent data, blockchain interactions, and AI-powered analysis.

| Tag | Description |
|-----|-------------|
| **incidents** | Create, list, and retrieve disaster incidents |
| **evidence** | Manage evidence collected by drones (IPFS-backed) |
| **blockchain** | Record and query on-chain events, verify locations |
| **solana** | Airspace management, delivery records, and permits |
| **auth** | JWT-based authentication |

## Coordination API

Built with TypeScript/Elysia. Handles real-time fleet operations and mission coordination.

| Tag | Description |
|-----|-------------|
| **Fleet** | Telemetry batch processing |
| **Intelligence** | Incident reporting and predictive alerts |
| **Storage** | IPFS file uploads |
| **Simulation** | Fault injection for testing |
| **Admin** | Service health, profiling, mission approval (EU AI Act Art. 14 HITL) |
| **Observability** | Prometheus metrics and SSE event streams |
