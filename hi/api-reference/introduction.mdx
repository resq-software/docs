## Infrastructure API

Rust/Axum से निर्मित। स्थायी डेटा, ब्लॉकचेन इंटरैक्शन और AI-संचालित विश्लेषण को संभालता है।

| Tag | विवरण |
|-----|-------|
| **incidents** | आपदा घटनाओं को बनाएँ, सूचीबद्ध करें और पुनः प्राप्त करें |
| **evidence** | ड्रोन द्वारा एकत्रित साक्ष्य का प्रबंधन (IPFS-समर्थित) |
| **blockchain** | ऑन-चेन घटनाओं को रिकॉर्ड व क्वेरी करें, स्थानों का सत्यापन करें |
| **solana** | एयरस्पेस प्रबंधन, डिलीवरी रिकॉर्ड और परमिट |
| **auth** | JWT-आधारित प्रमाणीकरण |

## Coordination API

TypeScript/Elysia से निर्मित। रियल-टाइम फ्लीट संचालन और मिशन समन्वय को संभालता है।

| Tag | विवरण |
|-----|-------|
| **Fleet** | टेलीमेट्री बैच प्रसंस्करण |
| **Intelligence** | घटना रिपोर्टिंग और भविष्यसूचक अलर्ट्स |
| **Storage** | IPFS फ़ाइल अपलोड्स |
| **Simulation** | परीक्षण के लिए फ़ॉल्ट इंजेक्शन |
| **Admin** | सेवा स्वास्थ्य, प्रोफाइलिंग, मिशन अनुमोदन (EU AI Act Art. 14 HITL) |
| **Observability** | Prometheus मेट्रिक्स और SSE इवेंट स्ट्रीम्स |
