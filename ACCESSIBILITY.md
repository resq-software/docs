# Accessibility

This statement covers the ResQ documentation site at [docs.resq.software](https://docs.resq.software), which is built from this repository.

## Target

We aim for the site to meet the [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) at level AA.

## Status

The site has **not yet been formally audited** against WCAG 2.2 AA, and this repository does not yet run automated accessibility checks. Until it has been audited, we can't say how far the site meets the target.

The site runs on Mintlify, which provides the page layout, navigation and search. This repository controls the content, the theme colors in `docs.json`, the styles in `custom.css`, and the images and diagrams.

## Known issues

None recorded yet. Because the site hasn't been audited, there are probably barriers we haven't found, and we want to hear about them.

## Reporting a barrier

If part of the site is hard or impossible to use with your setup, tell us:

- open an issue at [github.com/resq-software/docs/issues](https://github.com/resq-software/docs/issues/new), or
- email `contact@resq.software` if you'd rather not use GitHub.

Please include the page address, what you were trying to do, and the browser and any assistive technology you were using.
